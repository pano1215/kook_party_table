# 모꾸 (모임 꾸미기) 서버판

- `index.html` : 앱 화면 (https로 열면 서버에 저장, 파일로 열면 예전처럼 브라우저에만 저장)
- `api/` : 버셀 서버 함수 (파티, 초대, 취향 카드, 설문, 유입·인터뷰 기록, 운영자 보기, AI 대리 호출)

## 버셀 환경변수
| 이름 | 필수 | 설명 |
|---|---|---|
| KV_REST_API_URL / KV_REST_API_TOKEN (또는 UPSTASH_REDIS_REST_URL / UPSTASH_REDIS_REST_TOKEN) | 필수 | Upstash Redis 연결. Storage에서 연결하면 자동으로 들어간다 |
| OPS_KEY | 권장 | 설정 → 운영자용에서 서버 기록을 볼 때 쓰는 비밀번호 |
| GROQ_API_KEY | 선택 | 넣으면 시연 모드가 아니라 실제 AI가 한 상을 추천한다 |

환경변수를 바꾼 뒤에는 다시 배포해야 적용된다.

## 확인
배포 주소 뒤에 `/api/config` 를 붙여 열면 `{"ai":…,"storage":true}` 가 보여야 한다. storage가 false면 저장소가 연결되지 않은 것.

## 유입 경로·핵심 행동 기록
- 채널 링크: `/?src=instagram` · `friend`(지인) · `kakao`(카카오 오픈챗) · `threads` · `naver_cafe` · `naver_blog`. 값이 없으면 직접 방문, 모르는 값은 기타.
- 서버가 직접 기록: 파티 생성(`/api/party` POST), 카드 제출(`/api/card`, 새 카드만), 메뉴 추천(`/api/party` PUT, 추천할 때마다), 인터뷰 신청(`/api/lead`).
- 브라우저가 보냄(`/api/track`): 방문(세션당 1번), 초대 링크 전달(전달할 때마다, 2초 안 연속 클릭만 1번), 배달앱 이동, 바로 주문(준비 중) 버튼 클릭(`order_interest`, 재료·밀키트·배달).
- 파티에 딸린 행동은 호스트가 들어온 채널로 묶인다. 사람 수는 익명 방문자 ID(`x-visitor`, 브라우저별 무작위 16자리)로 중복 없이 센다.
- 보기: `/#/ops` 에서 OPS_KEY 입력 → 채널별 퍼널표, CSV 내려받기. 저장 위치는 Redis `events` 목록(최근 5만 건).

## 인터뷰 신청(개인정보)
- 수집 항목: 휴대폰 번호. 목적: 사용자 인터뷰 일정 안내와 사례 지급 연락. 보유 기간: 신청일로부터 90일(Redis 만료로 자동 삭제).
- 서버에 `lead:{id}`로 저장하며 동의 시각·안내 문구 버전(`NOTICE`)을 함께 남긴다. 신청자는 같은 기기에서 "신청 취소"로 바로 지울 수 있다(`DELETE /api/lead`).
- 안내 문구를 바꾸면 `api/lead.js`의 `NOTICE`와 앱의 `LEAD_NOTICE`를 같은 날짜로 함께 바꾼다.

## 첫 화면 사진 바꾸기
- 저장소 맨 위에 `hero.jpg`를 올리면 첫 화면 아치 안의 그림 대신 그 사진이 보인다(없으면 기본 그림). 직접 찍었거나 사용 권한이 있는 사진만 올린다.

## 초대 링크 보내기 창
- 파티를 만들면 초대 링크를 복사하고 보내기 창(카카오톡·인스타그램·링크 복사)을 띄운다. 호스트 화면의 "초대 링크 보내기"로 다시 열 수 있다.
- 카카오톡: 환경변수 `KAKAO_JS_KEY`(카카오 개발자 콘솔의 JavaScript 키, 사이트 도메인 등록 필요)가 있으면 카카오 공유 창을 연다. 없으면 휴대폰의 공유 창을 쓰고, 그것도 없으면 링크를 복사해 붙여 넣도록 안내한다.
- 인스타그램: 웹에서 메시지에 링크를 바로 넣는 방법이 없어, 링크를 복사하고 인스타그램 메시지 화면을 연다.
- 전달 방법(kakao·instagram·copy)은 `invite_shared` 기록의 `kind`로 남는다.

## AI 추천 연결 (사용자는 키를 넣지 않는다)
- Vercel 프로젝트 Settings → Environment Variables 에 `GROQ_API_KEY` 를 넣고 다시 배포하면, 모든 사용자의 메뉴 추천이 서버를 거쳐 AI로 만들어진다. 키는 브라우저로 나가지 않는다.
- 모델은 `openai/gpt-oss-120b` → `qwen/qwen3.8-27b` → `openai/gpt-oss-20b` 순서로 시도한다. 맨 앞 모델을 바꾸려면 `GROQ_MODEL` 을 넣는다.
- 키가 없으면 고정 견본 메뉴가 나온다(게스트 취향은 반영되지 않음). 실제 사용자에게 열기 전에 반드시 키를 넣는다.
- 확인: `/api/config` 에서 `"ai":true`.
